# SENTINEL

SENTINEL is an autonomous threat-intelligence platform that ingests live IOC feeds,
validates and enriches indicators, maps them to MITRE ATT&CK, generates detection
artifacts, and closes the loop with analyst feedback and constrained self-improvement.

## Project Status

Prompt 1 scaffold is in place. Core packages, skill files, data models, scheduler
plumbing, and local development infrastructure are ready for feature implementation.

## Quickstart

1. Copy `.env.example` to `.env` and fill in integration keys.
2. Run `docker-compose up --build`.
3. Extend the scaffold by working through the remaining prompts in `CODEX.md`.
